# Fun With *Psi4*

This resource is intended to help organic chemistry students set up the [***Psi4*** computational chemistry software](https://psicode.org) {cite:p}`psi4` on their own computer and perform a series of small calculations. It supports my course in **physical organic chemistry**, CHEM 4410. We will be using computational chemistry to demonstrate some important concents in **organic chemistry**, and we won't be thinking too much about how it works. There is another course available to students that explores computational chemistry in detail. CHEM 4320 will take you much farther if you catch the bug here. I hear that CHEM 4320 is all math, but CHEM 4410 is all fun. Let us have some **fun with *Psi4***.

## How to Use this Book

Navigate to the chapter of your choice using the **left sidebar** or the hamburger menu in the upper left corner. Most of the pages in this book are [*Jupyter* notebooks](https://jupyter.org) {cite:p}`granger2021jupyter` that you can open in [*Google Colab*](https://colab.research.google.com) {cite:p}`googlecolab2024` to run the code. You can also **follow the instructions** in this book to set up your own personal computer to run *Python* and *Psi4*. **Have fun**!

This book is a *Myst* book and is produced using markdown files and *Jupyter* notebooks that are converted to a web book format using the [*Myst* parser](https://mystmd.org) {cite:p}`mystmd_cli`
