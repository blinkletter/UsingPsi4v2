# Fun With *Psi4*

This resource is intended to help organic chemistry students set up the ***Psi4*** computational chemistry software on their own computer and perform a series of small calculations. It supports my course in **physical organic chemistry**. We will be using computational chemistry to demonstrate some important concents in organic chemistry, and we won't be thinking too much about how it works. There is another course available to students that explores computational chemistry in detail. It will take you much farther if you catch the bug here. I hear that that course is all math, but mine is all fun. Let us have some **fun with *Psi4***.
